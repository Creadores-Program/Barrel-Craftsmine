# 手工音乐(Beta)

以前称为**Barrel CraftsMine***

用于**Nukkit-MOT**的原生协议翻译插件,可将服务器兼容性从**Protocol 113(MCPE 1.1.0)**扩展至**Protocol 80(MCPE 0.15.0)**,使经典的Minecraft Pocket Edition客户端能够与现代版本并列,无需外部代理,且对本机客户端(`>=1.1.0`)无开销。

-

历史与建筑

该项目最初最初被设想为一个独立的代理(**Barrel CraftsMine**),后来演变为“100%原生架构”,作为Nukit-MOT**的插件。直接在网络栈和服务器世界引擎上运行时,可消除RakNet的双重序列化,降低延迟,确保适合游说团体、小型游戏(TNT Run、TNT Tag、Parkour)和多版本服务器的理想稳定会话。

## 积分与技术参考
** 开发与架构:*** 创作者计划(Trollhunters501)在代码工程代理的**谷歌AI工作室*的协助下。

#支持的协议(80 – 113+)

| 协议 | MCPE 版本 | RakNet | 翻译策略 |
|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

| `90 - 91` | `0.15.90` – `0.17.0` | | Varints 首字母缩写,ID `PacketsIds91`, 块,带有经典的订购和 ARGB 生物群落 |

| `110 - 112` | `1.1.0.0` – `1.1.0.9` | | | | | | IDs `PacketsIds110`,改编自 `MovePlayerPacket` (`ridingEid`)
| `113+` | `1.1.0` – `1.26.x` | `v8-v11` | **Nukkit-MOT** 原生(自动脱钩,无性能影响)|

## 主要特点

**实时直桥:仅为使用旧版本(`< 113` 的玩家截取并翻译传入和传出的套餐,使现代玩家的流动得以保留。
*** 块状和世界适应:** 自动将现代子块转换为由 MCPE 0.15.x 支持的平面块和生物色素格式,在 0.15 后重新映射块 ID,以避免客户端强制关闭。
*** 聊天与遗产命令兼容性:** 从 0.15.x 客户端发送的指令的双向消息翻译和透明执行。
*** 集中设置:** 来自 `config.yml` 的总桥度行为控制、数据包诊断和兼容性设置。

-

## 安装

1。下载或编译插件 `.jar` 文件。
2。将“CraftsmineNKM-1.0.0.jar`”放入服务器的“插件/`”文件夹中**Nukkit-MOT**。
3。启动或重新启动服务器以生成 `plugins/CraftsmineNKM/config.yml` 配置文件。
4.如果希望允许经典的 0.15.x 客户免费访问,请确保在“server.properties”中启用了严格的版本/Xbox 实时验证。

# 项目状态与说明
- 主要针对 MCPE 0.15.10(第 84 号协议)在小游戏和超世界环境中进行优化。
