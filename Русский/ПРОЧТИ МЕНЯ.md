# CraftsMineNKM (Бета)

> *Ранее известный как **Barrel CraftsMine***

Нативный плагин трансляции протоколов для **Nukkit-MOT**, который расширяет совместимость сервера с **Протокола 113 (MCPE 1.1.0)** до **Протокола 80 (MCPE 0.15.0)**, позволяя классическим клиентам Minecraft Pocket Edition играть вместе с современными версиями без внешних прокси и с нулевой нагрузкой для нативных клиентов (`>= 1.1.0`).

---

## История и Архитектура

Изначально задуманный как независимый прокси (**Barrel CraftsMine**), проект эволюционировал в **100% нативную архитектуру в виде плагина для Nukkit-MOT**. Работая непосредственно поверх сетевого стека и игрового движка сервера, он устраняет двойную сериализацию RakNet, снижает задержку и гарантирует стабильные сессии, идеально подходящие для лобби, мини-игр (TNT Run, TNT Tag, Parkour) и мультивселенных серверов.

### Авторы и Технические Ссылки
* **Разработка и Архитектура:** Creadores Program (Trollhunters501) при содействии агентов по разработке кода в **Google AI Studio**.
* **Обратная Разработка и Справочник Протоколов:** Основано на структурах пакетов и сетевых сопоставлениях из [MySoft-0.15.x-1.21.x](https://github.com/Dr1xyDev/MySoft-0.15.x-1.21.x) (справочный код мультивселенного PocketMine) и спецификациях устаревших протоколов MCPE.

## Поддерживаемые Протоколы (80 – 113+)

| Протокол | Версия MCPE | RakNet | Стратегия Трансляции |
|----------|-------------|--------|----------------------|
| `80 - 84` | `0.15.0` – `0.15.10` | `v7` | Фиксированное кодирование (BE/LE), без VarInts, чанки на 128 столбцов, обход ResourcePacks и переназначение устаревших блоков/биомов |
| `90 - 91` | `0.15.90` – `0.17.0` | `v8` | Начальные VarInts, ID `PacketsIds91`, чанки с классическим порядком + биомы ARGB |
| `92 - 101` | `1.0.0` – `1.0.4.0` | `v8` | Сабчанки XZY, ID `PacketsIds100`, `BatchPacket` с префиксом `0x06` |
| `102 - 107` | `1.0.4` – `1.0.9` | `v8` | ID `PacketsIds102` / `PacketsIds105`, сжатый `LoginPacket` |
| `110 - 112` | `1.1.0.0` – `1.1.0.9` | `v8` | ID `PacketsIds110`, адаптация `MovePlayerPacket` (`ridingEid`) |
| `113+` | `1.1.0` – `1.26.x` | `v8-v11` | **Нативная обработка Nukkit-MOT** (автоматическое отключение трансляции без потери производительности) |

## Основные Возможности

* **Прямой Мост в Реальном Времени:** Перехватывает и транслирует входящие и исходящие пакеты исключительно для устаревших клиентов (`< 113`), оставляя поток данных для современных игроков полностью нетронутым.
* **Адаптация Чанков и Мира:** Автоматическое преобразование современных сабчанков в плоский формат блоков и биомов, поддерживаемый MCPE 0.15.x, с переназначением ID блоков, добавленных после 0.15, для предотвращения вылетов клиента.
* **Совместимость Устаревшего Чата и Команд:** Двусторонняя трансляция сообщений и прозрачное выполнение команд, отправленных в виде обычного текста с клиентов 0.15.x.
* **Централизованная Конфигурация:** Полный контроль над поведением моста, диагностикой пакетов и настройками совместимости напрямую из файла `config.yml`.

## Установка

1. Скачайте или скомпилируйте `.jar` файл плагина.
2. Поместите `CraftsmineNKM-1.0.0.jar` в папку `plugins/` вашего сервера **Nukkit-MOT**.
3. Запустите или перезапустите сервер для генерации файла конфигурации по пути `plugins/CraftsmineNKM/config.yml`.
4. Убедитесь, что строгая проверка версии или Xbox Live отключена или скорректирована в `server.properties`, если вы хотите разрешить свободный вход с классических клиентов 0.15.x.

---

## Сборка из Исходного Кода

Требуется **Java (JDK 17+)** и **Apache Maven**:

```bash
mvn clean package
```

Скомпилированный артефакт будет создан по пути:
```text
target/CraftsmineNKM-1.0.0.jar
```

## Статус Проекта и Примечания

* Оптимизировано в первую очередь для **MCPE 0.15.10 (Протокол 84)** в режимах мини-игр и мирах Верхнего мира (Overworld).
* Рекомендуется ограничить доступ к современным измерениям (таким как обновленный Нижний мир / Nether) или использовать правила быстрого возрождения (*Fast Respawn*) для обеспечения максимальной стабильности на устройствах с ограниченными ресурсами.
